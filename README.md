# PG-SAC-6DOF-Robot-Simulation
The paper presents a physics-guided Soft Actor-Critic (PG-SAC) framework for a 6-DOF industrial manipulator in PyBullet, using a temporally aware state with historical energy (Ehistory) and Optuna/TPE reward tuning. The reported results: 17.5 J total energy vs 29.5 J for PID, 211 mm mean tracking error, 17,800 rad/s³ max jerk, &amp; 85% success rate.
